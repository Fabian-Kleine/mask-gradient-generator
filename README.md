## ✨ About

A small React + Vite app for building CSS `mask-image` / `-webkit-mask-image` linear gradients.
Adjust direction and multiple opacity stops, preview the result, then copy either plain CSS or Tailwind-friendly classnames.

> [!NOTE]  
> This App was completly generated by **GPT-5.2**

## ⭐ Features

- Build a `linear-gradient(...)` mask with up to 6 stops
- Direction presets plus custom angle input
- Live preview of the generated mask overlay
- Copy outputs:
  - Plain CSS (includes `mask-image` + `-webkit-mask-image` + repeat/size)
  - Tailwind v3 classnames (arbitrary properties)
  - Tailwind v4 classnames (`mask-[...]` arbitrary value)
- Syntax-highlighted output using `prism-react-renderer`

## 🏁 Getting Started

Prereqs:

- Node.js 20.19+ (or 22.12+) recommended for Vite 7
- pnpm

1. **Install dependencies:**

```bash
pnpm install
```

2. **Run the development server:**

```bash
pnpm dev
```

3. Open http://localhost:5173 in your browser.

4. **Production build (optional):**

```bash
pnpm build
pnpm preview

## 🧩 Where the code lives

- Main UI: `src/components/mask-gradient-generator.tsx`

```
